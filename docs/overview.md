# Overview Singkat Computer Vision

Computer Vision (CV) mencoba mengekstrak informasi bermakna dari citra atau video. Pada level dasar, CV melibatkan operasi seperti:

- Akuisisi gambar (membaca file atau stream)
- Pra-pemrosesan (resize, normalisasi, konversi warna)
- Operasi piksel (filtering, blur)
- Analisis fitur (deteksi tepi, corner detection)

Project ini fokus pada pengenalan operasi-operasi dasar tersebut menggunakan OpenCV.
