# Struktur Folder

- `images/` : tempat menyimpan gambar input. Tambahkan gambar contoh di sini untuk bereksperimen.
- `results/` : output dari script (gambar hasil, plot). Direkomendasikan untuk di-ignore di `.gitignore`.
- `src/` : semua kode Python berada di dalam folder ini. `main.py` adalah entrypoint sederhana.
- `docs/` : catatan pembelajaran, roadmap, dan referensi singkat.
